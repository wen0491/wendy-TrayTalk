# 饭卡 · 校园食堂点评推荐

帮同学发现食堂新菜、避开踩雷窗口的单页网页，无需构建，直接打开 `index.html` 即可使用。

## 功能
- **帮我决定**：按预算、口味、赶课时间随机推荐，并自动避开评分低、踩雷率高的菜
- **好评榜 / 新品尝鲜 / 避雷榜**：按评分、价格、排队时间、点评人数排序
- **窗口排队**：按时段估算排队时间，同学可随手反馈，30 分钟内有效
- **点评**：星级、文字、拍照上传；每条点评支持「有用」和评论
- 数据与点评保存在浏览器本地（localStorage）

## 说明
菜品数据为虚构示例。后续计划：多人共享点评与照片、接入真实菜单、窗口实时排队。
